CV–JD labelling
Guideline (read once)

Grade how well the CV fits this JD, on evidence in the CV, as a hiring manager would. 0 not relevant: a core must-have is absent, or only claimed or hedged ("familiar with", "currently learning"). 1 weak or adjacent. 2 good partial fit: you would phone-screen. 3 strong fit with demonstrated work: you would interview. Judge evidence, not keywords (a tool in a skills list is a claim; a project that used it is evidence). Ignore anything that is not job-related. Grade alone: do not discuss pairs with the other annotator until both of you have downloaded your labels. Keys 0–3 grade, ← → move.
