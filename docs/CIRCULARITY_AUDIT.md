## Separation rules

1. Reports name columns `ours-silver`, `coding-rubric`, and `Djinni-human`; the ambiguous `ours` label is not used for a human result.
2. Same-family LLM-as-judge metrics may be logged only as `blocked` diagnostics.
3. The 120 Hoa–Phúc labels validate label reliability, but targeted sampling cannot produce an official full-pool nDCG score.
4. Only the frozen 424-pair Djinni Aggregate Human Gold can currently support an external human-labelled ranking claim; unjudged pairs are ignored rather than treated as zero.
5. Every future LLM-rank artifact must persist the exact candidate order and label provenance so it can be rescored without another model call.

## Pre-registered release gate

Unfreeze `rank_shortlist` only if a no-tuning Djinni run records all eight per-JD orders and the Aggregate Human Gold comparison is non-inferior to its deterministic base (mean ΔnDCG@10 ≥ −0.01), with the point estimate, JD bootstrap interval, conservative P@5, and lower/upper label-sensitivity bounds reported. A positive claim additionally requires the paired 95% bootstrap interval for ΔnDCG@10 to exclude zero.
