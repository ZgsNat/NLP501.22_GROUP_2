PROFILE

Web test automation engineer with six years in product companies and agencies. Most of my work is end-to-end testing for React and Next.js applications, first with Cypress and since 2022 mainly with Playwright and TypeScript. I like owning a suite from the first test to the CI pipeline, and I care about tests that developers actually read and trust. For the past three years I have combined a full-time position at a SaaS company with part-time freelance work for small teams, which gave me a wide view of how different organisations set up their quality processes.

WORK EXPERIENCE

Senior QA Automation Engineer, B2B SaaS company (HR and payroll platform)
Jan 2021 – Present

– Took over a Cypress suite of 380 tests that failed on roughly one run in five. Found that most failures came from shared test accounts and hard-coded waits; introduced per-test data seeding through an internal API and replaced waits with network aliases. Flaky failures fell below 2% within four months.
– Led the migration from Cypress to Playwright and TypeScript during 2022. Moved 310 of the 380 tests (the rest were retired as duplicates), wrote typed fixtures for authentication and tenant setup, and designed page components in a shared package that three squads now import.
– Configured GitHub Actions to shard the Playwright suite across 6 runners. Full regression dropped from 48 minutes to 11 minutes. Traces and videos are uploaded for every failure, and a nightly job posts a summary to the team channel.
– Added API-level checks using Playwright's request context for tenant provisioning and payroll calculation endpoints, so that many scenarios no longer need the UI.
– Introduced visual snapshot tests for the five most customer-visible pages with a strict review process for baseline updates.
– Wrote the team's testing guide and ran two workshops, after which developers began adding their own Playwright tests for new features.
– Mentor two junior engineers and review all test pull requests.

Freelance QA Automation Consultant (part-time, in parallel with the role above)
Mar 2022 – Dec 2024

– Worked about 10 hours a week for three small clients, one at a time, building initial end-to-end suites for web shops and a booking site.
– For a booking startup, built a Cypress suite of 60 tests in JavaScript with custom commands for the calendar widget, and set up a GitHub Actions workflow that runs on every pull request.
– For an online shop, built a Playwright suite with Docker-based test environments and a nightly run against staging; handed it over with documentation and a recorded walkthrough.
– Reviewed a client's flaky tests and recommended stable selector conventions (data-test attributes) and a retry policy limited to network errors.

Ways of working that I carry between teams: tests are written in the same pull request as the feature whenever the feature is testable; every test has an owner listed in a CODEOWNERS file; the test report is read in the daily stand-up for the first ten minutes after a red build; and flaky tests are never retried silently but listed in a visible quarantine report. At the SaaS company I also run a short monthly review of the slowest twenty tests, which keeps the suite from slowly growing back to its old runtime. I split my week so that the freelance work never touches the employer's code, tools or schedule: freelance hours are in the evenings and weekends, and the clients know that availability is limited.

QA Automation Engineer, Digital agency
2019/06 – 2020/12

– Maintained Jenkins jobs that ran the suites after each deployment and sent HTML reports to project managers.
– Tested REST endpoints with Postman collections and ran them with Newman in the same pipelines.
– Started to move the template repository to TypeScript, which became the base for later projects.

Junior Tester, Digital agency
