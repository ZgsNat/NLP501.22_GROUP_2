## Summary
Performance testing specialist with 8 years in banking and trading platforms. Designs load, stress and endurance tests with JMeter and Gatling, analyses bottlenecks and reports to architects. Does not do functional UI automation.

## Experience
### Senior Performance Test Engineer — Banking software vendor (2019–2025)
- Built a JMeter + Gatling test suite for core banking APIs simulating 8,000 concurrent users and 1,500 transactions per second.
- Created realistic workload models from production logs and tuned think times, pacing and data pools.
- Found a database connection pool bottleneck that cut p95 latency of the transfer API from 2.8 s to 0.9 s after tuning.
- Integrated JMeter runs into Jenkins with threshold-based pass/fail and Grafana/InfluxDB dashboards.
- Ran distributed tests with JMeter on Docker containers across 10 load generators.
- Wrote capacity-planning notes with throughput and response-time curves, which the architects used for infrastructure sizing.

### Performance Tester — Stock trading software company (2016–2019)
- Wrote JMeter scripts with correlation and parameterisation for order-entry and market-data services.
- Monitored CPU, memory and GC behaviour with VisualVM and Prometheus during tests.
