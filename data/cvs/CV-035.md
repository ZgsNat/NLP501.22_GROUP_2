## Summary / Tóm tắt
Mobile automation engineer với 4 năm kinh nghiệm, làm việc cho các ứng dụng ví điện tử và giao đồ ăn. Xây dựng framework Appium dùng chung cho Android và iOS, chạy trên emulator trong CI và trên cloud device farm trước mỗi release.

## Kinh nghiệm làm việc
**Mobile QA Automation Engineer — Công ty ứng dụng ví điện tử** (2022/04 – nay)
● Thiết kế framework Appium + Java + TestNG với Page Object Model, một codebase cho cả Android và iOS (khoảng 70% code dùng chung).
● Tự động hóa 140 kịch bản quan trọng: onboarding, nạp tiền, thanh toán QR, quản lý thẻ.
● Chạy test trên emulator/simulator trong GitHub Actions cho mỗi pull request, và trên device farm cho release candidate (12 thiết bị, nhiều phiên bản OS).
● Xử lý các vấn đề riêng của mobile: permission dialog, push notification, deep link, mạng chập chờn.
● Phối hợp với dev mobile thống nhất accessibility id cho các màn hình mới.

**Mobile Tester — Công ty phần mềm giao đồ ăn** (2020/09 – 2022/03)
● Kiểm thử thủ công trên thiết bị thật; từ 2021 viết các test Appium bằng Python cho 40 luồng chính.
● Dùng Postman để kiểm tra API backend của ứng dụng.
