## About the role
We deliver embedded-adjacent and enterprise web projects for international clients, where Robot Framework is the agreed keyword-driven standard. We need an engineer to write and extend Robot Framework suites with custom Python libraries, and to maintain them inside client CI pipelines.

## Responsibilities
- Write Robot Framework test suites for web and API layers using SeleniumLibrary and RequestsLibrary.
- Develop custom Python keyword libraries and resource files that other testers can reuse.
- Maintain test data, variables files and environment configuration for several client projects.
- Run and debug suites in Jenkins or GitLab CI and publish Robot reports.
- Review keyword naming and suite structure with the team lead.
- Report test progress to the project manager and the client.

## Requirements
Must have:
- 2+ years of Robot Framework in real projects.
- Python programming, including writing custom libraries.
- Experience with SeleniumLibrary for web testing.
- Experience with CI (Jenkins or GitLab CI).
- Working English for client meetings and reports.

Nice to have:
- API testing with RequestsLibrary or Python requests.
- pytest or behave experience.
- Docker.
- Experience with several clients or domains.
