## About the role
We are a fast-growing mobile commerce startup shipping weekly. Our QA team is small, so every engineer owns quality end to end. We need an automation engineer to build and scale our end-to-end tests for the web app and our mobile apps.

## Responsibilities
- Build and maintain the end-to-end test suite for the web application with Playwright and TypeScript.
- Contribute to mobile test automation for iOS and Android.
- Run tests on every pull request in GitHub Actions, and keep the pipeline fast (under 15 minutes).
- Work with developers to decide what to cover at unit, API and UI level.
- Debug failing tests quickly using traces, logs and videos, and keep flaky rates low.
- Improve test tooling and share best practices in the team.

## Requirements
Must have:
- Hands-on experience with Playwright and TypeScript for web end-to-end testing.
- 3+ years in test automation, with ownership of a framework or suite.
- Experience with CI pipelines (GitHub Actions or similar).
- API testing experience (Postman or code-based).

Nice to have:
- Appium experience for mobile apps (a plus).
- Docker and basic cloud knowledge.
- Experience in a startup or fast-release environment.
- Comfort working across web, mobile and backend.
