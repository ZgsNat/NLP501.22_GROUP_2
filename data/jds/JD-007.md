## About the role
We are an outsourcing company delivering web products for clients in Europe and Southeast Asia. A new team is starting a React-based project and needs an automation tester who can write and maintain Cypress tests from day one. You will work with a senior engineer who sets the framework direction.

## Responsibilities
- Write and maintain end-to-end tests in Cypress using JavaScript.
- Extend existing page objects and custom commands rather than inventing new structures.
- Run the suite in the team's CI pipeline and report results to the project manager.
- Investigate failures with the developers and log defects clearly.
- Update tests when requirements change and keep the test documentation current.

## Requirements
Must have:
- At least 1 year of hands-on experience writing Cypress tests.
- Working knowledge of JavaScript (ES6, async/await, promises).
- Basic understanding of Git and of CI pipelines.
- Good understanding of Agile teams and of writing clear bug reports.
- Working English for client communication.

Nice to have:
- TypeScript.
- Experience with Postman or API tests inside Cypress.
- ISTQB Foundation.
- Experience in an outsourcing environment.
