## About the role
We are a B2B SaaS startup with a web dashboard used daily by logistics operators. We release several times a day and want end-to-end tests that developers trust. You will own the Playwright suite, grow it with the product, and help the team decide where UI tests stop and API tests begin.

## Responsibilities
- Build and own the Playwright + TypeScript end-to-end suite for the web application, including fixtures, page abstractions and test data setup.
- Run the suite on every pull request in GitHub Actions, sharded and parallel, with a target under 12 minutes.
- Diagnose failures from traces, screenshots and videos; drive flaky tests to near zero.
- Add visual and accessibility checks where they pay off.
- Pair with developers on testability: stable selectors, seeded test environments, feature flags.
- Write short guides so that developers can add tests without the QA team.

## Requirements
Must have:
- 3+ years in web test automation, with at least 1 year of Playwright in a real project.
- Strong TypeScript (async code, types, modules).
- CI experience with GitHub Actions or similar, including parallel execution.
- Ability to design a maintainable test structure, not only write individual tests.

Nice to have:
- API testing with Postman or code-based clients.
- Docker, and experience with preview or ephemeral environments.
- Experience with Cypress or Selenium before moving to Playwright.
- Visual regression testing.
