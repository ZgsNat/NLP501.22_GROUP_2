## About the role
Our bank's digital platform is a set of around 80 REST services behind mobile and web channels. We are strengthening the automated API test layer so that regression of payment, account and card services runs on every build. This role is API-only: no UI automation.

## Responsibilities
- Design and maintain an API test framework in Java using RestAssured (or Postman/Newman collections where they fit better).
- Build data-driven tests for payment, account and card services, covering positive, negative and boundary cases.
- Integrate API tests as quality gates in Jenkins or GitLab CI, publishing results as audit-ready evidence.
- Work with developers on API specifications (OpenAPI) and on consumer-driven contract testing.
- Manage test data and mocks for downstream dependencies.
- Review API test code from other squads.

## Requirements
Must have:
- 3+ years of API test automation experience.
- Hands-on RestAssured with Java, or Postman/Newman at scale.
- Understanding of REST, HTTP status semantics, authentication (OAuth2, JWT) and JSON schema validation.
- Experience running API tests in CI (Jenkins or GitLab CI).
- Solid test design skills, including negative and boundary testing.

Nice to have:
- Contract testing with Pact.
- SQL for data setup and verification.
- Banking, payments or other regulated domain experience.
- ISTQB certification.
