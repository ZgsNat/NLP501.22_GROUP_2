## About the role
We build a subscription platform used by more than a million customers. Our quality team is looking for an engineer who can automate performance and API tests and make them part of the delivery pipeline.

## Responsibilities
- Design and run load, stress and endurance tests with JMeter or k6 against our backend services.
- Build automated API test suites with Postman/Newman or RestAssured and run them in CI.
- Define performance baselines and thresholds, and fail builds that regress them.
- Analyse results with monitoring tools (Grafana, Prometheus) and report bottlenecks to developers.
- Maintain test environments and test data in Docker.
- Document test approach and share findings with engineering leads.

## Requirements
Must have:
- 3+ years of experience in performance or API test automation.
- Hands-on experience with JMeter or k6.
- Experience with Postman/Newman or RestAssured.
- Experience integrating tests into CI/CD (Jenkins, GitHub Actions or GitLab CI).

Nice to have:
- Gatling, Python or JavaScript/TypeScript scripting.
- Knowledge of Docker and Kubernetes.
- ISTQB certification.
- Understanding of database and caching performance.
