## About the role
We make a consumer fintech app for Android and iOS with a weekly release train. Manual regression on devices has become our bottleneck. We need an engineer who can build reliable mobile test automation and make it part of every release.

## Responsibilities
- Design and build the Appium test framework for our Android and iOS apps, shared where possible between platforms.
- Automate the critical user journeys (onboarding, payment, card management) and keep them green on every release candidate.
- Run tests on a cloud device farm and on emulators or simulators inside CI.
- Handle mobile-specific problems: permissions, push notifications, deep links, flaky gestures, network conditions.
- Collaborate with mobile developers on accessibility identifiers and testability.
- Report device and OS coverage to the product team.

## Requirements
Must have:
- 2+ years of mobile test automation with Appium, on both Android and iOS.
- Programming skills in Java, Python or TypeScript for test code.
- Experience running mobile tests in CI (Jenkins, GitHub Actions or GitLab CI).
- Understanding of the mobile app lifecycle and of real-device versus emulator trade-offs.

Nice to have:
- Native frameworks: Espresso (Android) or XCUITest (iOS).
- Experience with a cloud device farm.
- API testing for the mobile backend.
- Experience in a startup or a fast-release environment.
