## About the role
We run an e-commerce marketplace with strong seasonal peaks. Before every major campaign we need to know how the platform behaves under load. We are hiring a Performance Test Engineer to design realistic workloads, run them continuously in CI and tell us where the bottlenecks are.

## Responsibilities
- Design load, stress, spike and endurance tests with k6 or JMeter based on production traffic patterns.
- Build performance tests as code and run them in CI against pre-production, with pass/fail thresholds.
- Build Grafana dashboards (with Prometheus or InfluxDB) to follow latency percentiles, error rates and resource saturation.
- Analyse results, find bottlenecks together with backend and database teams, and write clear findings.
- Create realistic test data and manage test environments with Docker.
- Define performance baselines and track regressions release over release.

## Requirements
Must have:
- 3+ years of performance testing experience.
- Hands-on k6 or JMeter, including scripting parameterised scenarios.
- Experience with Grafana or similar monitoring dashboards.
- Experience running performance tests in CI (Jenkins, GitHub Actions or GitLab CI).
- Ability to interpret percentile latencies, throughput and saturation, not only report averages.

Nice to have:
- Gatling or Locust.
- Kubernetes and cloud load generation.
- JavaScript or Python scripting.
- Database and caching performance knowledge.
